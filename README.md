# PersonalLab

PersonalLab is a modular, offline-first self-improvement tracking app for a single user on iPhone. It is a React + TypeScript Progressive Web App, installed through Safari "Add to Home Screen", that stores all data locally on the phone. It ships with Gym, Nutrition and Chess modules on top of a shared core (profile, settings, backup, updates, navigation, dashboard and command menu), and new modules plug into a module registry.

Status: in development on `feature/personal-lab`.

The requirements, design and implementation plan are in [`.kiro/specs/personal-lab/`](.kiro/specs/personal-lab/).
